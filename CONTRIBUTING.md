# Contributing

Thanks for your interest in improving the OSINT Sentinel Workstation.

**The source code is private.** This repository is the public face of
the project — downloads, docs, and issue tracking. We don't accept code
pull requests here, but there are real ways to contribute:

## How to contribute

### Report bugs

Use the [Bug Report](../../issues/new?template=bug_report.yml) template.
Include:

- App version (shown in the title bar / installer filename)
- Operating system
- Steps to reproduce
- What you expected vs what happened
- Screenshots or console errors if you have them

### Suggest features

Use the [Feature Request](../../issues/new?template=feature_request.yml)
template. Tell us the problem you're solving — the use case matters more
than the implementation.

### Ask questions

Use the [Question](../../issues/new?template=question.yml) template,
[GitHub Discussions](../../discussions), or the
[Discord](https://discord.gg/visentrix).

### Plugins (future)

A plugin SDK is planned — plugins will be the supported way to extend
the workstation without access to the Core Engine. Watch this repo for
the SDK announcement.

## Ground rules

All participation is covered by the [Code of Conduct](CODE_OF_CONDUCT.md).
Be respectful; assume good intent.

**Do not** file public issues for security vulnerabilities — see
[SECURITY.md](SECURITY.md).
