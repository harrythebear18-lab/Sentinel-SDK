# Support

## Getting help

| Channel | Best for |
|---------|----------|
| [GitHub Issues](../../issues) | Bugs, feature requests, tracked work |
| [GitHub Discussions](../../discussions) | Ideas, show-and-tell, open Q&A, community threads |
| [Discord](https://discord.gg/visentrix) | Quick questions, community help, discussion |

## Before you file

1. Update to the [latest release](../../releases/latest) — your issue may
   already be fixed
2. Search [existing issues](../../issues) to avoid duplicates
3. Check [PRIVACY.md](PRIVACY.md) for data-handling questions

## What to include in a bug report

- App version and OS
- Steps to reproduce
- Expected vs actual behavior
- Screenshots or console errors

## Security issues

Never file security vulnerabilities as public issues — see
[SECURITY.md](SECURITY.md) for the private reporting process.

## Licensing
