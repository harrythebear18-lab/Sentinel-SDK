# Support

## Getting help

| Channel | Best for |
|---------|----------|
| [GitHub Issues](../../issues) | Bugs, feature requests, tracked work |
| [GitHub Discussions](../../discussions) | Ideas, show-and-tell, open Q&A, community threads |
| [Discord](https://discord.gg/denat8G6ze) | Quick questions, community help, discussion |

## Before you file

1. Read [`sdk/earth-engine-plugin.d.ts`](../sdk/earth-engine-plugin.d.ts)
   and the [example module](../examples/hello-overlay/)
2. Search [existing issues](../../issues) to avoid duplicates
3. Check [`docs/SUBMISSION.md`](../docs/SUBMISSION.md) for lifecycle rules

## What to include in a bug report

- SDK/module contract question or doc issue
- Workstation version you're targeting
- Steps to reproduce
- Expected vs actual behavior

## Security issues

Never file security vulnerabilities as public issues — see
[SECURITY.md](SECURITY.md) for the private reporting process.
